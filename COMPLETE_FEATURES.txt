🚀 HOW TO USE THE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: INITIALIZE DATABASE
cd backend
python3 init_database.py

STEP 2: START BACKEND
python3 main.py

STEP 3: START FRONTEND (new terminal)
cd frontend
npm run dev

STEP 4: LOGIN
http://localhost:5173/login

Users:
  - screener_test / ScreenerPass123!
  - checker_test / CheckerPass123!
  - finalizer_test / FinalizerPass123!

STEP 5: UPLOAD BLACKLIST
Navigate to: http://localhost:5173/upload
Upload: test_data/sample_blacklist.csv
Threshold: 70%
Click: "Upload & Screen"

STEP 6: BULK REVIEW
1. Go to Checker Review page
2. Check boxes next to items
3. Click "Review X Items"
4. Review each item:
   - See KAMCO vs Blacklist comparison
   - Choose decision: Flagged/Not Flagged/Escalate
   - Add notes
5. Check "Generate Reports" if needed
6. Click "Submit All"

STEP 7: VIEW REPORTS
- Reports generated automatically
- Download PDFs
- Email to teams
